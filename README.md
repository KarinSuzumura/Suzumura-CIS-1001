# Suzumura-CIS-1001
CIS 1001 Section 802—Activity 4

Art Link is a mobile app which helps art enthusiasts discover art museums, exhibitions, and events. It helps them to find art-related information by having it concentrated in one platform instead of individual websites. This application has information about event periods, opening hours, what artworks are there, locations, and reviews by other users. It saves time by 2 hours for finding this information, helping people to discover and plan their art journeys more effectively.
