Application Key Features

- Reviews and ratings
Users can write and read reviews, including photos to help them decide where to visit
- Map
Map with all locations listed to help users see how far it is
- Search
Users can search by names of artists, museums, event or exhibition names to find relevant information
- Bookmark
Users can bookmark (save) museums, artists or events/exhibitions inside the app to not forget
- Venue information
Users can find information like address, opening hours, what artworks can be seen
